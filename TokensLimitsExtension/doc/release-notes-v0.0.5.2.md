# TokensLimitsExtension v0.0.5.2 — кандидат не опубликован

Release workflow собрал подписанные пакеты, но остановился на проверке: Windows runner не доверяет self-signed цепочке сертификата и `Get-AuthenticodeSignature` вернул `UnknownError`. Публичных артефактов v0.0.5.2 нет. Исправление проверки включено в [v0.0.5.3](release-notes-v0.0.5.3.md), однако его deployment gate тоже завершился ошибкой до публикации. Актуальный кандидат — [v0.0.5.4](release-notes-v0.0.5.4.md).

Версия v0.0.5.1 также не публиковалась: release build передавал MSBuild форматированный объект вместо значения `Thumbprint`. В v0.0.5.2 аргумент исправлен, а `AppxPackageSigningEnabled=true` включает штатную подпись MSIX во время сборки.

## Что изменилось

- Обычные страницы провайдеров, отдельные Dock detail pages и dock items повторно используются при включении и выключении провайдеров. Число удерживаемых объектов ограничено числом провайдеров; отключённые поверхности пусты, отписаны от cache и не запускают запросы.
- Все UI-поверхности читают одно состояние кэша. Ошибка обновления сохраняет последнее значение как устаревшее, а recovery-действия показывают следующий шаг и копируют только безопасную диагностику.
- Чтение Codex session JSONL и auth-файлов, HTTP-ответы и внешние provider CLI ограничены по объёму, времени или памяти. JSONL читается инкрементально, включая неполный конец файла.
- CI использует locked restore, проверяет Debug tests и Release-сборки x64/ARM64.
- Автоматическая проверка через Authenticode завершилась ошибкой цепочки доверия; v0.0.5.3 закрепил signer за `.cer` и сверил блоки содержимого с подписанной block map. Его Windows deployment gate завершился до публикации; актуальный кандидат — v0.0.5.4.

## Проверки перед полевой установкой

Локально прошли locked restore, Debug build с `-warnaserror`, 119 unit-тестов, 22 integration-теста и тесты release helper для кода v0.0.5.2. Релизный workflow не прошёл проверку подписи, поэтому пакеты не публиковались.

Перед стабильным выпуском остаются проверки в живом host:

- проверить Overview, обычную страницу, Dock, действия, toggle-навигацию, ошибки и устаревшее состояние, а также штатное завершение COM host;
- измерить удерживаемые объекты, allocations/GC и UI events после повторных переключений и работы в Command Palette;
- выполнить upgrade с предыдущего подписанного MSIX, сохранив настройки и provider secrets; устанавливайте новую версию поверх предыдущей, не удаляя пакет (см. [release.md](release.md));
- проверить ARM64 runtime на совместимом устройстве.

Артефакты полевой проверки будут доступны на [странице v0.0.5.4](https://github.com/NFoxNet/tokens_bar_pt_palette/releases/tag/v0.0.5.4), если release workflow завершится успешно. Ссылка `releases/latest` продолжит вести на последний стабильный выпуск. Установка описана в [release.md](release.md).
