# TokensLimitsExtension v0.0.5.7

## Изменения

- Ручное обновление получает новый snapshot даже при свежем кэше. Общий запрос и cooldown сохраняются; смена интервала или credentials не оставляет провайдер без автоматических повторов.
- Сводка Dock и overview использует реальные длительности и существующие окна, показывает баланс и сохраняет пометку оценки. Ошибки timeout, авторизации, конфигурации и rate limit различаются; Retry-After сохраняется при ошибках нескольких источников.
- Нативные Details показывают источник, тариф и свежесть. Контекстные действия позволяют обновить данные, открыть HTTPS-кабинет и скопировать безопасную диагностику. Пустой overview открывает штатные настройки; EN/RU тексты обновляются при смене языка.
- Codex auth читается из первого CODEX_HOME, а локальный fallback учитывает все перечисленные каталоги.
- Azure OpenAI больше не выполняет inference при автоматическом обновлении. Явная команда «Проверить подключение» отправляет один deployment-запрос и предупреждает о возможном расходе квоты; результат — connection health, а не остаток аккаунтной квоты.
- Отмена одного ожидающего не отменяет общий запрос. Поздние ответы и ошибки старых credentials не перезаписывают состояние нового аккаунта.
- Удалён неиспользуемый код; документация содержит матрицу возможностей источников и исправленные пути сборки.

## Проверки

Перед подготовкой версии интегрированная ветка прошла 168 unit-тестов и 53 integration-теста, Debug x64 и Release x64/ARM64. В Release остаются известные внешние IL2104 предупреждения WinRT SDK.

Публикация выполняется существующим release workflow только после тестов, подписанной сборки двух архитектур, проверки сертификата/manifest/COM identity/block map/checksums и Windows x64 deployment gate. Статус этого workflow проверяется отдельно после отправки тега.

## Обновление и оставшиеся проверки

Устанавливайте подписанный MSIX поверх предыдущей версии с той же identity. Не удаляйте установленный пакет перед обновлением: удаление может привести к потере provider secrets.

Live Command Palette/Dock, ARM64 runtime и обновление с реальными настройками/секретами не проверялись локально. После установки проверьте навигацию Dock → Details → главная палитра, контекстные команды, переполнение и сохранность настроек. Избранные Dock, история, экспорт и уведомления остаются отложенными.
