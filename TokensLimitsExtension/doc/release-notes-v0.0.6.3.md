# TokensLimitsExtension 0.0.6.3

Settings cards now expand when you click their full-width heading, with a disclosure arrow on the right. Separate Configure buttons have been removed. Provider cards display the same bundled provider logos used elsewhere in the extension.

Only the active section or provider contributes form fields. Opening or closing a card does not save settings or run field validation. Saving keeps the current card open and uses the existing settings validation and protected secret storage. Save edits before switching cards.

Upgrade in place with the signed package for your architecture. The package identity, publisher, and signing certificate are unchanged. Do not uninstall first. Package preparation does not install or publish the release.

Live PowerToys rendering and keyboard focus, ARM64 runtime, and an upgrade with real user settings require separate verification.
