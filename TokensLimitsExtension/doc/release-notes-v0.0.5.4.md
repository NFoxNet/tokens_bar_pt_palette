# TokensLimitsExtension v0.0.5.4 — предварительный выпуск

v0.0.5.4 — первый публикуемый кандидат для изменений из v0.0.5.2. Версии v0.0.5.2 и v0.0.5.3 не создали GitHub Release: первая остановилась на проверке недоверенной цепочки, вторая — на неподдерживаемом удалении обычного signed MSIX с `-PreserveApplicationData`. В v0.0.5.4 исправлена последовательность Windows deployment gate. Приложение оставляется установленным на одноразовом GitHub-hosted runner до уничтожения runner; на нём нет пользовательских данных.

## Что входит

- UI обычных страниц провайдера и Dock повторно используется при переключении настроек; отключённые поверхности снимают подписки и не обновляют данные.
- Общий cache сохраняет последнее значение при временной ошибке обновления, а recovery-действия показывают следующий шаг и копируют безопасную диагностику.
- Чтение Codex session/auth файлов, HTTP-ответы провайдеров и внешние CLI ограничены по объёму, времени и памяти; JSONL читается инкрементально с сохранением неполной последней строки.
- Release workflow собирает x64 и ARM64; проверяет CMS-подпись, сертификат, manifest, COM CLSID, signed block map, хэши payload и checksums.
- Windows deployment gate на x64 проверяет, что два читаемых изменения ZIP metadata отклоняются как ошибка подписи/целостности, а исходный MSIX устанавливается и регистрирует ожидаемую identity и архитектуру.
- `unregister.ps1` отказывается удалять подписанный Release MSIX в режиме сохранения данных; для локальных dev-mode регистраций сохранение работает, а удаление данных требует явного `-DeleteApplicationData`.

## Проверки перед стабильным выпуском

GitHub release workflow должен успешно завершить сборку, структурные проверки, Windows deployment gate и публикацию prerelease. Проверка подписи пользователя на локальной машине не заменяет проверки целевой установки.

На целевой машине проверьте:

- Overview, страницу провайдера, Dock, actions, переключение настроек, ошибки и stale state, а также штатное завершение COM host;
- удерживаемые объекты, allocations/GC и UI events после повторных переключений и длительной работы в Command Palette;
- ARM64 runtime на совместимом устройстве;
- подписанное обновление с предыдущего MSIX с сохранением settings и provider secrets. Устанавливайте новую версию поверх предыдущей, не удаляйте пакет перед обновлением; инструкции приведены в [release.md](release.md).

После успешного workflow артефакты появятся на [странице v0.0.5.4](https://github.com/NFoxNet/tokens_bar_pt_palette/releases/tag/v0.0.5.4). Ссылка `releases/latest` остаётся на последнем стабильном выпуске.
