# TokensLimitsExtension v0.0.5.5 — релиз

Этот выпуск обновляет MSIX до v0.0.5.5 и добавляет автоматическое завершение установки через управление жизненным циклом PowerToys.

## Изменения

- Если PowerToys запущен, установщик просит runner штатно завершиться до установки пакета и перезапускает его после завершения установки.
- Ранее запущенный PowerToys запускается снова, даже если установка завершилась ошибкой или пользователь отменил UAC. Если PowerToys изначально не работал, установщик не запускает его сам.
- Перед закрытием проверяется, что найденное окно трея принадлежит обнаруженному процессу PowerToys. Установщик ждёт завершения до 30 секунд и не завершает процесс принудительно.
- Если PowerToys не удаётся штатно закрыть, установка прекращается с инструкцией закрыть его вручную. Существующие настройки и защищённые ключи сохраняются при обновлении поверх текущего MSIX.
- Запускайте `.cmd` двойным щелчком, без «От имени администратора»: временное повышение применяется только к установке, а PowerToys перезапускается с обычными правами пользователя.
- UAC должен повысить права той же учётной записи Windows, под которой работает PowerToys: MSIX регистрируется для пользователя. При вводе учётных данных другого администратора установщик остановит установку.
- Установщик отклоняет запуск из уже повышенной оболочки. Запускайте его обычным способом, чтобы PowerToys после установки не получил права администратора.

## Проверки, выполненные для релиза

Локальная проверка прошла: сборка Debug x64 без предупреждений, 119 unit-тестов и 22 integration-теста. Тесты установщика прошли в Windows PowerShell 5.1; проверены отмена/ошибка установки, отказ при ошибке остановки, проверка владельца окна и порядок импорта сертификата с установкой пакета. Read-only проверка текущего PowerToys подтвердила, что установщик находит окно трея у процесса runner.

После установки проверьте в целевой среде:

- обновление с предыдущего MSIX, когда PowerToys запущен, и автоматический перезапуск;
- отмену UAC и ошибку установки с последующим запуском ранее работавшего PowerToys;
- установку, когда PowerToys не запущен;
- сохранение настроек и provider secrets после in-place update;
- x64 и ARM64 runtime на совместимых устройствах.

Эти live-проверки не выполнялись в CI и остаются полевой проверкой. См. [инструкции по установке и релизам](release.md).
