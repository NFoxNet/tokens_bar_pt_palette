# Языки и иконки

## Локализация

Пакет содержит полный базовый словарь `lang/en.json` и русский перевод
`lang/ru.json`. Английский — гарантированный fallback. Файлы — UTF-8 JSON с
`culture`, `nativeName` и объектом `strings`; подстановки используют `{0}`.

При запуске расширение читает упакованную папку `lang`, затем
`%LOCALAPPDATA%\TokensLimitsExtension\lang`. Пользовательский файл может
добавить язык или переопределить отдельные строки. Неправильный внешний файл
пропускается, а отсутствующий ключ берётся из английского словаря.

Настройка `tokensLimits.language` поддерживает `auto` и все корректно
загруженные языки. В `auto` сначала выбирается точная Windows UI-культура,
затем её родитель (например, `ru-RU → ru`), затем английский. Выбранный, но
позднее удалённый пользовательский язык безопасно откатывается к английскому;
значение настройки сохраняется. Язык интерфейса не меняет региональный формат
дат и чисел Windows и не инвалидирует usage cache.

## Иконки

Поставляемые SVG и PNG 32/64/128 находятся в
`TokensLimitsExtension/Assets/Providers`. Это офлайн-копии выбранных
`ProviderIcon-*.svg` из CodexBar revision
`392310c665485f8d57c93881e7416c5ebf69d8ef`. Контрольные суммы и исходные
пути — в `CodexBar-icons.manifest.json`; текст MIT и атрибуция — в
`THIRD_PARTY_NOTICES.md`.

Не все логотипы дают права на использование товарных знаков. Ресурсы с явной
ссылкой на отдельные внешние brand terms не включены; для них и неизвестных
provider ID используется нейтральная иконка.
