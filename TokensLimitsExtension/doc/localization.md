# Языки и иконки

## Локализация

Пакет содержит полный базовый словарь `lang/en.json` и русский перевод
`lang/ru.json`. Английский — гарантированный fallback. Файлы — UTF-8 JSON с
`culture`, `nativeName` и объектом `strings`; подстановки используют `{0}`.

При запуске расширение читает упакованную папку `lang`, затем
`%LOCALAPPDATA%\TokensLimitsExtension\lang`. Пользовательский файл может
добавить язык или переопределить отдельные строки. Неправильный внешний файл
пропускается, а отсутствующий ключ берётся из английского словаря.

## Полные языковые пакеты

Для нового перевода создайте `lang/<culture>.json` с `culture`, `nativeName` и
`strings`. Бренды провайдеров (например, Codex и DeepSeek) не переводятся.
Все остальные подписи, включая каждое поле настроек, должны быть в `strings`.
Ключи полей имеют стабильный вид
`settings.field.<fieldKey>.label` и `settings.field.<fieldKey>.description`;
например, `settings.field.apiKey.label`. Описание переменной окружения
формирует общий ключ `settings.field.environmentVariable` с `{0}` для
описания и `{1}` для имени переменной.

`LocalizationKeyCatalog.RequiredKeys` — программный контракт полного пакета.
Интеграционный тест проверяет, что `en.json` и `ru.json` покрывают его и что
форматные строки корректны. Добавляя поле провайдера, обновите оба базовых
пакета: тест не позволит случайно выпустить неполный перевод. Пользовательские
файлы остаются частичными по замыслу — они безопасно дополняются английским
fallback.

Настройка `tokensLimits.language` поддерживает `auto` и все корректно
загруженные языки. В `auto` сначала выбирается точная Windows UI-культура,
затем её родитель (например, `ru-RU → ru`), затем английский. Выбранный, но
позднее удалённый пользовательский язык безопасно откатывается к английскому;
значение настройки сохраняется. Язык интерфейса не меняет региональный формат
дат и чисел Windows и не инвалидирует usage cache.

Переключение языка обновляет уже созданную форму настроек, в том числе
переключатели провайдеров, описания полей, placeholder секретов и ошибки
валидации, без сетевого обновления и без изменения сохранённых значений. Метрики
локального Codex используют стабильные ключи `metrics.tokens5h` и
`metrics.tokens7d`, поэтому подписи количества токенов также меняются вместе с
языком.

## Иконки

Поставляемые SVG и PNG 32/64/128 находятся в
`TokensLimitsExtension/Assets/Providers`. Выбранные значки CodexBar скопированы
из revision `392310c665485f8d57c93881e7416c5ebf69d8ef`; для Ollama использован
`ProviderIcon-ollama.svg` из revision
`cf79d1310493f2d028af62cc21e422b5f33c70a5`, по MIT-лицензии CodexBar. Источники
и контрольные суммы собраны в `CodexBar-icons.manifest.json`, атрибуция и текст
лицензии — в `THIRD_PARTY_NOTICES.md`.

Растровые варианты имеют общий нейтральный круглый фон с контрастной обводкой:
он делает чёрные и белые монохромные знаки читаемыми на светлой и тёмной теме.
Для Augment, ClinePass и Vertex AI используются собственные буквенные значки,
поскольку исходные брендовые значки не входят в проверенный набор. OpenAI и
Azure OpenAI используют знак Codex, Moonshot — знак Kimi. Неизвестные ID
сохраняют нейтральную иконку.
