# TokensLimitsExtension v0.0.5.8

Кандидат следующей версии: изменения направлены на расход управляемой памяти.

## Изменения

- Codex fallback удерживает события только от включительной границы семи дней
  и события с будущим временем. Накопительные счётчики и позиция дозаписи
  сохраняются; старая читаемая история возвращает нулевой текущий расход.
  При откате часов нужные события восстанавливаются повторным чтением файла.
- Overview обновляет строку изменившегося провайдера, переиспользуя Details и
  контекстные команды. Смена языка и состава остаётся общей пересборкой;
  конкурентные события не перезаписываются устаревшей публикацией.
- Detail pages с общим кэшем создают строки при первом `GetItems()` хоста.
  До этого хранится последнее состояние; отключение освобождает граф строк.
  Общая metadata готовится один раз, содержимое Details каждой строки остаётся
  индивидуальным. Обычная и Dock страницы сохраняют отдельные объекты.
- Обычный UTF-8 JSON разбирается из bounded byte buffer без промежуточной
  UTF-16 строки; parse-only endpoints обходятся без дополнительной копии
  массива. Существующие charset, текстовые форматы, body limits и отмена
  сохраняются.

## Проверки и измерения

Интегрированная ветка прошла locked restore, Debug x64 с `-warnaserror` и
Release x64/ARM64. В Debug и Release x64 прошли 258 тестов: 191 unit и 67 integration.
Debug собран без предупреждений; в каждой Release сборке остаются два известных внешних
IL2104 предупреждения WinRT SDK. Проверки PowerShell helper, unregister и
installer прошли без ошибок. Независимое финальное ревью и дополнительный
запуск 149 целевых тестов не выявили воспроизводимых замечаний.

Методика и результаты synthetic comparison находятся в
[отдельном отчёте](../research/2026-10-05-memory/RESULTS.md).
Выделенные байты и число удерживаемых событий не равны working set процесса.
Live Command Palette/COM, ARM64 runtime и обновление установленного MSIX
этой проверкой не подтверждены. Частота опроса и правила свежести не менялись.

После подписанного обновления проверьте Dock → Details → главную палитру,
смену языка, отключение/включение провайдера и сохранность настроек. Обновление
выполняйте поверх установленного пакета с той же identity, без удаления MSIX.
