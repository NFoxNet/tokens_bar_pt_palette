# Security policy

Do not open a public issue for a vulnerability that could expose credentials, account data or execute code on a user's machine. Use GitHub's private security advisory feature for this repository instead.

Never include API keys, OAuth tokens, cookies, `%CODEX_HOME%` files or raw provider responses in a report. A redacted reproduction, version, Windows/PowerToys version and relevant non-secret log lines are enough to start triage.

Supported versions: the latest public release and the `master` branch.
